## Current Layout

The active draw.io diagram is generated by `render_drawio.js` from `flow_model.json` and `flow_rules.js`. It contains 93 editable flowchart elements arranged in 7 left-to-right program-scheme lanes. The A1 template, border, and original bottom-right title block are preserved.

The layout intentionally avoids a serpentine main flow. Each main lane reads left-to-right; row transitions use connector pairs only when a direct line would become long, crowded, or visually ambiguous. The generated page currently uses 91.5% of the available width and 96.8% of the available height.

## Rule System

`flow_rules.js` is the single source for symbol ratios, connector semantics, branch labels, label overrides, row wrapping, open-arrow rules, visual density, long-line limits, routing envelope limits, and program-scheme layout constraints.

`render_drawio.js` consumes these rules and refuses to render non-compliant routes. It does not draw `auto_row_*` or `auto_grid_*` synthetic edges as visible business lines.

`validate_drawio.js` consumes the same rules and fails the build for visible synthetic edges, isolated connectors, connector locality violations, overused connector-resolved edges, long bus lines, excessive bends, route envelope escapes, wrong arrow styles, label placement violations, unreadable truncated labels, node/edge crossings, and forbidden title-block overlap.

The validator also enforces the latest visual fixes: right-upper row spacing must be uniform, same-row adjacent business edges must be straight horizontal links, horizontal main-lane connection length must match the global 112 px standard, vertical connector/branch connection length must match the global 88 px standard, and node text must stay inside symbol-safe padding.

## Connector Policy

Connector pairs are allowed only when they make the drawing clearer than a long or crossing line. The current connector set is F1, P1, and R1 through R8. Local connector edges must be visible, close to their semantic endpoints, and comparable to normal flow-line length. Horizontal connector stubs use the 112 px standard; vertical connector stubs use the 88 px standard.

`connectorResolvedEdgeIds` is currently empty. Ordinary business edges are not hidden as connector-resolved logic.

## Arrow Policy

Left-to-right and top-to-bottom visible lines have no arrowhead. Right-to-left and bottom-to-top visible lines use the open draw.io arrow style `endArrow=open;endFill=0;endSize=12`. Block, classic, filled, diamond, oval, and circle arrowheads are rejected.

The validator also checks that reverse-arrow stems are long enough to be readable, so open arrows do not appear cramped under short vertical stubs.

## Branch And Merge Policy

Decision labels are placed adjacent to their branch path: horizontal labels above the segment, vertical labels to the right of the segment. Labels must not overlap lines, arrowheads, nodes, other labels, or the title block.

Normal business nodes must have a single direct input. Multiple inputs are allowed only at explicit merge nodes: Input Merge, Config Merge, Safety Merge, and Fault Merge.
